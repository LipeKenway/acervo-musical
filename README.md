\# Acervo Musical



Pipeline de dados para catalogação e análise de biblioteca musical pessoal (\~919 GB, 110k+ faixas).



\## Status

Fase inicial: estrutura do projeto e scanner de arquivos.



\## Estrutura

\- `src/ingest`: descoberta de arquivos e extração de metadados

\- `src/transform`: limpeza e padronização

\- `src/load`: carga no banco

\- `data/`: dados locais (não versionados)
